## 📌 About the Project

**BankSecure** is a Machine Learning-powered fraud detection system designed to identify suspicious financial transactions.

The application analyzes transaction-related information and uses a **Random Forest classification model** to predict whether a transaction is potentially fraudulent.

The project provides an interactive **Streamlit web application** where users can analyze transactions and understand their associated fraud risk.

---

💻 How It Works
The user provides transaction information through the Streamlit interface.
The application processes the transaction data.
Relevant features are prepared for the Machine Learning model.
The Random Forest model analyzes the transaction.
The system predicts the possibility of fraud.
The result is displayed through the interactive dashboard.
Users can review the transaction risk information and generate a report.


🔍 Fraud Detection
The system uses a Random Forest Classifier, an ensemble Machine Learning algorithm that combines multiple decision trees to make predictions.
Random Forest is suitable for this project because it can:
Handle multiple transaction features.
Capture non-linear relationships.
Reduce overfitting compared with a single decision tree.
Provide reliable classification performance.
